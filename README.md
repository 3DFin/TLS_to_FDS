**An open-source Python framework and GUI for converting semantically segmented 3D point clouds into Fire Dynamics Simulator (FDS) computational domains.**

---

### Overview
**TLS_to_FDS** bridges the gap between high-resolution remote sensing and computational fluid dynamics (CFD). Wildland fire modeling requires highly accurate spatial representations of forest fuels. This tool takes semantically segmented 3D point clouds (such as those generated by Terrestrial Laser Scanning) and automates their spatial discretization into physics-based Fire Dynamics Simulator (FDS) voxel domains.

It dynamically assigns literature-derived combustion properties, parameterizes atmospheric boundary conditions, and generates ready-to-run `.fds` input scripts alongside optimized Fortran Binary Data Format (`.bdf`) voxel arrays.

### Key Features
* **Zero-Code GUI:** Built with PySide6 (Qt6), providing a fully tabbed, interactive interface for atmospheric parameterization, ground-fuel layer initialization, and FDS boundary condition setup.
* **2-Stage Micro-Voxelization Dynamic Bulk Density:** Sub-voxelizes point clouds at 1 cm to eliminate scan alignment and range attenuation biases, accurately capturing intra-canopy clustering and fuel gaps while preserving total dry fuel mass.
* **1D Boundary Fuel Model (BFM) Litter Discretization:** Two decoupled scientific ground fuel models (Stem Distance Decay and Canopy Turnover Integration with Gaussian Wind Dispersion) mapped to contiguous 2D ground `&VENT` patch tiles.
* **Dual Spatial Raster Exports:** Automatically exports GeoTIFF (`.tif`), publication-ready PNG heatmaps, and CSV matrices for both 2D ground litter bulk density ($\text{kg/m}^3$) and surface fuel load ($\text{kg/m}^2$).
* **Interactive 3D Pre-Simulation Visualizer:** Generates stand-alone Plotly 3D HTML previews (`fds_scene_preview.html`) with cubic voxel rendering, 5% visual seam gap shrinkage, continuous thermal colormaps, wind vectors, tree stems, and ignition footprints.
* **Decoupled Science via Presets:** Combustion properties (bulk density, surface-to-volume ratio, moisture fraction, drag) are managed via external JSON presets for biome customization.
* **Advanced FDS Physics Integration:** Automatically configures multi-mesh MPI parallel domains, coarse sky meshes, Monin-Obukhov similarity boundary layers, and explicit Lagrangian firebrand/ember tracking with empirical char/ash material density overrides.
* **Dynamic Spatial Ignition:** Automatically snaps ignition boundaries (line fires, corner burns, perimeter strips, spot fires) to the exact geometric footprint of the forest plot.
* **High-Performance Voxelization:** Utilizes `dendroptimized` and `numpy` C-backends to process millions of LiDAR points in seconds without freezing the UI, thanks to multithreaded `QThread` workers.

### Installation & Requirements

There are two ways to use TLS_to_FDS depending on your needs:

#### 1. Standalone Application (Recommended for Users)
You do not need Python installed to run TLS_to_FDS. Simply navigate to the **Releases** page on this GitHub repository and download the latest executable for your operating system (Windows `.exe` or macOS/Linux binary). Extract the file and run it directly.

#### 2. Python Development Environment (For Contributors)
If you wish to modify the source code or run the application from source:

1. Clone this repository to your computational environment:
    ```bash
    git clone https://github.com/3DFin/TLS_to_FDS.git
    cd TLS_to_FDS
    ```
2. Ensure you have Python 3.9+ deployed.
3. Create and activate a virtual environment.
4. Install the package in editable mode with development dependencies:
    ```bash
    pip install -e .[dev]
    ```
5. Launch the application via the registered CLI command:
    ```bash
    tls-to-fds
    ```
*(Note: The CI pipeline automatically enforces `ruff` styling and runs `pytest` on all pull requests.)*

## Quick Start Guide

### Step 1: Obtain Test Data
You can download a testing dataset from the UKCEH Environmental Information Data Centre:

Download Link: [UKCEH Catalogue - Wildfire Fuel Test Data](https://catalogue.ceh.ac.uk/documents/467a735f-b03c-4c30-8781-82f0e11aec28)

This dataset includes five segmented point clouds in LAS format, representing different fuel classes from a forest plot. The forest plot consists of a 40 x 40 m Pinus ponderosa plot scanned with a Riegl-VZ400i in Sycan Marsh, Oregon, USA. 

* `grass_crop.las`: 3D point cloud storing the fuel class "grass" present in the forest plot.
* `shrub_crop.las`: 3D point cloud storing the fuel class "shrub" present in the forest plot.
* `wood_crop.las`: 3D point cloud storing the fuel class "tree stem" present in the forest plot.
* `leaf_crop.las`: 3D point cloud storing the fuel class "tree branch+leaves" present in the forest plot.
* `leaf_crop_high.las`: 3D point cloud storing the fuel class "tree branch+leaves" after applying a virtual treatment (pruning branches below 3 m).
